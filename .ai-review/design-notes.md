# Design notes

Deliberate behaviour the reviewer cannot see in a diff. Read from the base branch.

- **Errors are HTTP 200 with `{"status":1,"message":...}`.** PrivateBin's JSON API does this and existing clients depend on it. Only the optional login gate returns HTTP 401. Flag if a change alters status codes for the PrivateBin endpoints (`POST /`, `GET /?<id>`, delete by token).
- **No accounts, no owner on pastes.** The delete token is HMAC-SHA256(salt, id) and is the only ownership proof. Flag if a change stores user identity next to a paste.
- **The burn flag lives in `adata[3]`, not a column.** This matches the PrivateBin 2.1.0 schema. Flag if a change adds columns to `paste`, `comment` or `config`; the extra `expiredate` index is the one allowed addition.
- **Reading a burn paste goes through `Service.Read` and `Take`.** `Take` is one atomic `DELETE ... RETURNING`; of concurrent readers exactly one wins. Covered by `TestTakeIsAtomic`. Flag if burn handling stops going through `Take`.
- **Discussions are not supported.** The `comment` table exists for schema compatibility only; comment requests return `status: 1`.
- **Client IP is the TCP peer unless `TRUSTED_PROXIES` is set.** Flag any use of `X-Forwarded-For` that bypasses `c.ClientIP()`.
- **`/metrics` is served on the app port, unauthenticated, when `METRICS_ENABLED` is true (the default).** Operators restrict it at their proxy. It must expose only route templates, methods, status codes and counters. Flag if a metric label or value ever carries a paste id, token, IP or request content.
- **The web interface is PrivateBin 2.1.0's, copied unmodified (`web/css`, `web/js`, `web/img`, `web/i18n`; sums in `web/PRIVATEBIN_FILES.sha256`).** It does its own encryption and compression, so no crypto lives in this repo's own code. Flag any edit to those files; upgrades re-copy a release and refresh the sums. The CSP is PrivateBin's default, which is why it contains `'wasm-unsafe-eval'` (zlib runs as WebAssembly) and a `sandbox` directive.
- **API messages say "Document", as PrivateBin 2.1.0 does** (`Controller.php`: GENERIC_ERROR, "Document is limited to %s of encrypted data.", "Wrong deletion token. Document was not deleted."). The older "Paste ..." wording is not 2.1.0's. Pinned by `TestMessagesAreKnownToPrivateBin`. Flag if a message is changed without a matching PrivateBin release.
- **`BURN_AFTER_READING_DEFAULT` defaults to `true` on purpose.** It only preselects the checkbox; the user can untick it and operators set it to `false` in `.env`. Documented in the README and `.env.example`. Flag if the server starts forcing the flag (it is chosen and authenticated in the browser).
- **`js/bootstrap-5.3.8.js` is used**: the page's navbar collapse, the password, burn-confirmation, QR and email modals use `data-bs-toggle`/`data-bs-dismiss`, and `privatebin.js` calls `new bootstrap.Modal`. A slimmer build would mean editing the copied file, which `TestCopiedFilesMatchRecordedSums` forbids. Flag if the template stops using Bootstrap components.
- **`js/legacy.js` `showError` assigns `innerHTML` for one literal.** It is a private function inside PrivateBin's old-browser check with a single caller passing a constant string. Editing it would break the unmodified-copy rule. Flag if a dynamic value is ever passed to it.
- **The CSP is PrivateBin 2.1.0's default, verbatim, except `connect-src 'self' blob:` (it uses `*`).** 2.1.0's own `cspheader` has `base-uri 'self'` and a sandbox of `allow-same-origin allow-scripts allow-forms allow-modals allow-downloads`, with no `allow-popups` or `allow-presentation`; `TestCSPMatchesPrivateBin210` pins it. Flag if the policy drifts from that string beyond `connect-src`, or if inline script or style is allowed.
